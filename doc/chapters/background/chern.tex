\subsection{The first Chern class of a line bundle}

We follow \cite[Section 1.4]{EH16}. Let $\mathcal{L}$ be a line bundle on a variety $X$ and $\sigma$ be a rational section. Then on an open affine set $U$ of a covering of $X$, we can write $\sigma|_U = f_U / g_U$, and define $\text{Div}(\sigma)|_U = \text{Div}(f_U) - \text{Div}(g_U)$. This definition agrees on the intersections of the open affine sets, and thus defines a Cartier divisor on $X$. Moreover, if $\tau$ is another rational section of $\mathcal{L}$, then $\alpha = \sigma / \tau$ is a well-defined rational function, so $\mathrm{Div}(\sigma)$ and $\mathrm{Div}(\tau)$ are rationally equivalent divisors: 
\[\mathrm{Div}(\sigma) - \mathrm{Div}(\tau) = \mathrm{Div}(\alpha) \equiv 0 \text{ mod } \mathrm{Rat}(X).\]

Thus, we can define the first Chern class of the line bundle $\mathcal{L}$ as
\[c_1(\mathcal{L}) = [\mathrm{Div}(\sigma)] \in A^1(X),\]
the rational equivalence class $\mathrm{Div}(\sigma)$  in the Chow group $A^1(X)$, for any nonzero rational section $\sigma$. This is well-defined, as it does not depend on the choice of rational section $\sigma$.

\begin{example}
    A consequence is that $c_1(\mathcal{O}_{\mathbb{P}^n}(d))$ is the class of any hypersurface of degree $d$ in $\mathbb{P}^n$.
\end{example}

\subsection{Chern classes of vector bundles}

We now extend the definition of Chern classes to vector bundles of higher rank. Let $\mathcal{E}$ be a vector bundle on an $n$-dimensional variety $X$, and let $r = \mathrm{rank}(\mathcal{E})$. We follow the approach of \cite[Section 5.2]{EH16}, giving an informal characterization rather than a formal definition.

In the case $r=1$, the Chern class $c_1(\mathcal{L})$ can be viewed as a measure of non-triviality. If $c_1(\mathcal{L}) = 0$, then $\mathcal{L}$ has a nowhere-vanishing section, and $\mathcal{L} \cong \mathcal{O}_X$. We extend this idea to higher rank vector bundles by considering the ``degeneracy locus'' of collections of sections. Roughly, this is the locus where the sections become linearly dependent in the fibers of $\mathcal{E}$.

More precisely, the bundle $\mathcal{E}$ is said to be trivial if and only if it has $r$ global sections  which are everywhere linearly independent. In this case, any set of $r$ general sections will do. \todo{Necessary?} We look at the exterior powers of $\mathcal{E}$. The $(r-i)$-th exterior power $\bigwedge^k \mathcal{E}$ is a vector bundle of rank $\binom{r}{r-i}$, and general sections $s_1, \dots, s_{r-i}$ induce sections of $\bigwedge^{r-i} \mathcal{E}$ given by $s_{1} \wedge s_{2} \wedge \dots \wedge s_{r-i}$. For $i=0$, we have a single section $s_1 \wedge s_2 \wedge \dots \wedge s_r$ of the line bundle $\bigwedge^r \mathcal{E}$, and the zero locus is by definition $c_1(\bigwedge^r \mathcal{E})$. This is a class in $A^1(X)$, and we call it the \emph{first Chern class of $\mathcal{E}$}.

In general, we have that for $(r-i)$ general sections, we can consider the vanishing locus of 
\[s_1 \wedge \dots \wedge s_{r-i} \in \bigwedge^{r-i} \mathcal{E}.\]
This vanishing locus is called the \emph{$i$-th degeneracy locus} of the sections $s_1, \dots, s_{r-i}$. Given general sections, the $i$-th degeneracy locus has codimension $i$ in $X$, and thus defines a class in $A^i(X)$. This class can be computed using Chern classes.

\subsection{Important results on Chern classes}

The \emph{$i$-th Chern class} $c_i(\mathcal{E})$ of the vector bundle $\mathcal{E}$ is defined as the class of the $i$-th degeneracy locus of $(r-i)$ general sections of $\mathcal{E}$, i.e. the class of the vanishing locus of $s_1 \wedge \dots \wedge s_{r-i} \in \bigwedge^{r-i} \mathcal{E}$ for general sections $s_1, \dots, s_{r-i}$.

To characterize the \emph{$i$-th Chern class} $c_i(\mathcal{E})$ of the vector bundle $\mathcal{E}$, we use the part (b) of the following theorem.

\begin{theorem}[\cite{EH16}, Theorem 5.3]
    There is a unique way of assigning to each vector bundle $\mathcal{E}$ on a smooth quasi-projective variety $X$ a class $c(\mathcal{E}) = 1 + c_1(\mathcal{E}) + \ldots + c_n(\mathcal{E}) \in A(X)$ in such a way that
    \begin{enumerate}[label=(\alph*)]
        \item If $\mathcal{L}$ is a line bundle, then $c(\mathcal{L})$ is $1 + c_1(\mathcal{L})$, where $c_1(\mathcal{L}) \in A^1(X)$ is the class of the divisor of zeros minus the divisor of poles of any rational section of $\mathcal{L}$.
        \item If $\tau_0, \dots, \tau_{r-i}$ are global sections of $\mathcal{E}$, and the degeneracy locus $D$ where they are all dependent has codimension $i$, then $c_i(\mathcal{E}) = [D] \in A^i(X)$.
        \item (Whitney sum formula) If $0 \to \mathcal{E} \to \mathcal{F} \to \mathcal{G} \to 0$ is an exact sequence of vector bundles on $X$, then $c(\mathcal{E}) = c(\mathcal{F}) c(\mathcal{G}) \in A(X)$.
        \item If $\phi \colon Y \to X$ is a morphism of smooth varieties, then 
        \[\phi^*(c(\mathcal{E})) = c(\phi^*(\mathcal{E})).\]
    \end{enumerate}
\end{theorem}

\begin{theorem}[\cite{EH16}, Theorem 5.12, Splitting principle]
    Any universal formula involving Chern classes of bundles that is true for bundles that are direct sums of line bundles is true in general.
\end{theorem}

\begin{corollary}[\cite{EH16}, Corollary 5.5]\label{cor:sums}
    If $\mathcal{E}$ is the direct sum of line bundles $\mathcal{L}_i$, then 
    \[c(\mathcal{E}) = \prod c(\mathcal{L}_i) = \prod (1 + c_1(\mathcal{L}_i)).\]
\end{corollary}

The following examples are from \cite{EH16}, example 5.13, 5.14, and 5.16.

\begin{example}[Vanishing]
    If $\mathcal{E}$ is a rank $r$ vector bundle, then $c_i(\mathcal{E}) = 0$ for $i > r$. To see why, apply the splitting principle to write $\mathcal{E} = \bigoplus_{i=1}^r \mathcal{L}_i$ for line bundles $\mathcal{L}_i$. Then, since $c(\mathcal{L}_i) = 1 + c_1(\mathcal{L}_i)$, the total Chern class $c(\mathcal{E}) = \prod (1 + c_1(\mathcal{L}_i))$ by \cref{cor:sums}. This is a product of $r$ factors each of degree at most 1, so any Chern class of degree greater than $r$ must be zero. 
\end{example}

\begin{example}[Duals]
    If $\mathcal{E} = \bigoplus \mathcal{L}_i$, Then
    \[c(\mathcal{E}^\vee) = \prod c(\mathcal{L}_i^\vee) = \prod (1 - c_1(\mathcal{L}_i))\]
    since $c_1(\mathcal{L}^\vee) = -c_1(\mathcal{L})$ when $\mathcal{L}$ is a line bundle. Given this, Whitney's formula gives
    \[c_i(\mathcal{E}^\vee) = (-1)^i c_i(\mathcal{E})\]
\end{example}

\begin{example}[Symmetric squares]

\begin{proposition}[\cite{EH16}, Proposition 6.4]\label{prop:degF}
    Let $V$ be an (n+1)-dimensional vector space, and let $S \subseteq V \otimes \mathcal{O}_\mathcal{G}$ be the tautological rank-(k+1) subbundle on the Grassmannian $\mathcal{G} = \mathcal{G}(k,\mathbb{P}V)$ of $k$-planes in $\mathbb{P}V \cong \mathbb{P}^n$. A form $g$ of degree $d$ on $\mathbb{P}V$ gives rise to a global section $\sigma_g$ of $\mathrm{Sym}^d S^\vee$ whose zero locus is the Fano scheme $F_k(X)$, where $X = V(g) \subseteq \mathbb{P}V$ is the hypersurface defined by $g$. Thus, when $F_k(X)$ has expected codimension $\binom{k+d}{k} = \mathrm{rank}(\mathrm{Sym}^d(S^\vee))$ in $\mathcal{G}$, its class in the Chow ring of $\mathcal{G}$ is given by the top Chern class
    \[[F_k(X)] = c_{\binom{k+d}{k}}(\mathrm{Sym}^d S^\vee) \in A(\mathcal{G}).\]
\end{proposition}

This is a powerful result, as it allows us to compute the degree of the class of the Fano scheme of $k$-planes on a general hypersurface using only Chern classes, when the Fano scheme has the expected dimension. We will put this to use in the next section.
